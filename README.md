# Técnicas de Diseño de Algoritmos - UBA

📚 Repositorio de estudio y recursos sobre **Técnicas de Diseño de Algoritmos** de la Facultad de Ciencias Exactas y Naturales de la Universidad de Buenos Aires.

## 📖 Contenido

Este repositorio contiene:
- Notas sobre técnicas fundamentales de diseño de algoritmos
- Guías de estudio y ejemplos resueltos
- Problemas propuestos y sus soluciones
- Análisis de complejidad y optimización
